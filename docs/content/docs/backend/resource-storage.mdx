# 文件存储

平台管理员在“平台管理 → 存储设置”选择本地或阿里云 OSS。默认本地，保存成功后对新文件生效。图片、视频、音频、普通文件、生成媒体和派生媒体共用资源保存入口；文本生成正文继续保存在任务记录中。

切换策略不会迁移历史文件。每条资源记录保存自己的位置，本地和 OSS 文件可以长期混合使用。页面统计按已就绪资源的实际位置汇总数量和容量，不把临时文件或播放缓存重复计入资源配额。

## 配置阿里云 OSS

使用私有 Bucket、标准 Region 和对应的官方 HTTPS Endpoint，例如区域 `cn-shanghai` 对应 `https://oss-cn-shanghai.aliyuncs.com`。首版不支持自定义域名、CDN 或浏览器直传。浏览器始终通过现有鉴权资源接口访问文件。

AccessKey ID 和 Secret 均使用工作区 `.settings-key` 加密，不向浏览器回显。表单只显示“已配置”；留空保留已有值，更换 ID 时必须同时提供匹配的 Secret。备份时须同时保存数据库与 `.settings-key`，并限制访问权限。密钥不要写入日志、文档、URL、审计正文或浏览器持久缓存。

“测试连接”使用当前草稿，在 `.beeftv-probe/` 下写入少量随机内容，读取并逐字节校验，然后删除。测试最长 25 秒，可取消；清理失败不会显示全部通过。取消或清理失败的测试对象进入持久清理流程，凭据仅以加密形式供清理使用，不会修改当前策略或配置版本。

启用 OSS 或提交 OSS 连接修改时，服务端重新执行验证，通过后才原子保存策略、位置、版本和审计。保存携带预期版本；其他管理员已修改配置时返回冲突。切回本地且不提交连接修改时无需 OSS 在线。

读写通过但删除返回 `storage_delete_permission`，表示 OSS 拒绝了 `DeleteObject`。需要为当前 AccessKey 所属的 RAM 用户或角色授权目标桶对象上的 `oss:DeleteObject`，并检查 Bucket Policy 或其他策略中的显式拒绝。只允许读写不足以通过连接测试；不要通过跳过删除检查启用存储。`storage_cleanup_record` 则表示远端文件已经删除，但本地清理记录更新失败，须检查本地数据库状态，无需因此扩大 OSS 权限。超时、网络错误和取消保留各自的错误分类。

更换 Endpoint 或 Bucket 会建立新的位置记录，历史资源继续引用原位置。同一位置轮换密钥后，该位置的历史资源使用新凭据。切回本地仍保留已有 OSS 位置，供历史文件读取和删除。

## 保存、回退与恢复

资源服务在开始写入时固定资源编号、上传身份和目标位置，先将内容流式保存为可重放的本地暂存文件。OSS 使用官方 Go SDK v2，较大文件按分片上传，限制并发和重试，并验证完整文件 CRC64。分片身份持久登记，失败或中断后可以继续清理。

只有远端写入及资源就绪记录提交均成功后，才释放本地暂存。提交失败时保留待完成资源及原始暂存，重试沿用同一个资源编号、上传身份和配额记录。后台维护会释放已提交资源因退出或暂时删除失败遗留的本地暂存。

OSS 写入失败时，同一份已完成的暂存文件转为本地资源，记录洗敏后的回退原因。不会创建第二份资源，也不会重复计算配额。回退成功的本地文件不会后台自动迁移到 OSS。用户取消不会被当作 OSS 故障而完成本地保存；暂存或元数据也无法保存时返回真实失败。

仅在 OSS 中的历史文件读取失败会显示真实错误并允许重试。网络、鉴权和限流错误不会被当成文件不存在，也不会触发新的付费生成。恢复生成结果仍使用原任务与原结果回执。

## 读取、媒体工具和删除

`GET /api/resources/:id/file` 校验归属后按资源自身记录读取本地或代理 OSS，支持单段 Range 和请求取消。不会把 OSS 凭据或持久签名链接返回给浏览器。上游协议需要地址时，服务端在归属校验后生成短期签名，仅用于当前请求。

媒体探测、视频截帧、音频分离与播放转码使用统一的临时本地文件端口，处理完成释放临时文件。可再生的播放副本继续保存在本地缓存中，原件位置不变。

删除沿用素材引用检查与持久删除任务，按原位置执行物理删除。OSS 拒绝删除或暂时不可达时保留待重试任务，不能报告物理清理成功。没有历史文件迁移、定时自动删除或收藏保留策略。

## 管理接口

接口合同见 [HTTP API](http-api.mdx)。所有管理请求沿用平台会话、来源、CSRF 和服务层管理员校验。配置、清理任务与位置记录使用已有 `SystemSetting`；资源和删除任务使用已有的 `Provider`、`StorageSettingID`、`Endpoint`、`Bucket`、`ObjectKey` 字段，无新增表或迁移。工作区运行模式 `storageMode` 不代表文件介质，不随存储策略改变。
