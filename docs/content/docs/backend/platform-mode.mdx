# 平台模式（开发中）

平台模式正在按阶段开发，当前实现了平台进程、一次性管理员初始化、会话认证及项目/画布的工作区边界，并接入了前端登录、强制改密、会话恢复、账号管理和模型目录管理。它还不是可部署的多用户产品。本页只记录已接入的代码合同，不代表升级任务书的全部能力已经交付。

## 启动与数据隔离

平台使用独立的 `backend/cmd/platform` 入口，通过 `platform` 构建标签编译。`cmd/desktop` 和既有 `cmd/server` 仍为 local 模式。平台需要显式提供 `CANVAS_PLATFORM_DATA_DIR` 和 `CANVAS_PLATFORM_ORIGIN`；相应 CLI 参数为 `--data-dir` 和 `--origin`，不能借用本地工作区目录或数据库。

local 与 platform 使用不同的数据目录、SQLite 数据库和 `.settings-key`。持久 SQLite 文件必须直接位于当前数据目录，不能放在嵌套子目录或通过本地 `DATABASE_URL` 指向其他目录；平台固定使用 `open_ai_canvas.db`。启动在打开数据库前检查路径，打开后再次核对实际文件，随后检查运行模式并执行业务 schema 与平台 schema 迁移。

数据库主文件不允许有多个硬链接。启动、备份和导入会在 SQLite 打开文件前拒绝共享同一物理数据库的硬链接副本，避免两个目录各自取得锁后并发写入。复制或恢复工作区应使用独立文件副本及相应维护命令。

桌面、本地服务和离线维护工具使用同一工作区锁，Windows 长短路径及目录别名映射到相同身份。Windows 同时持有用户级发现锁和工作区旁的物理锁，以阻止服务账号与维护账号同时写入；任一锁失败都会拒绝启动。运行账号需要访问数据目录、其父目录及已有锁文件的权限，跨账号维护还需配置相应 Windows ACL，工具不会自动放宽权限。正常退出会释放锁，锁文件本身不应手工删除。

目录中的 `.runtime-mode.json` 与数据库 `runtime_mode_markers` 保存同一模式及随机目录标识。模式不符、标记损坏、标识不一致，或目录已标记但数据库标记缺失时均拒绝启动。历史未标记数据库只允许 local 接纳；平台初始化要求空白的新目录，不能直接打开既有业务库、旧资源或旧主密钥。

若仅目录标记丢失，原模式可以根据数据库标记恢复它。已有数据库缺失主密钥则拒绝启动，不生成替代密钥。迁移前自动备份及离线备份、校验、恢复命令已接入，详见[平台备份与恢复](./platform-backup)。平台数据不能交给旧本地程序打开。已有本地工作区可使用[隔离导入](./platform-import)，当前只接纳规范 schema v29、唯一工作区和已完成审计的历史类型；不支持的历史会阻止整个导入。

## 身份与认证

平台身份包含模式、账号 ID、工作区 ID、角色、状态和会话 ID。账号与工作区一对一绑定，现有业务表的 `user_id` 保存工作区 ID；账号管理和审计使用账号 ID。请求正文和查询参数不能指定身份。管理员访问项目、章节和画布时也只使用自己的工作区。

首次管理员使用 CLI 的 `--bootstrap-admin` 引导，用户名、显示名、初始点数和存储上限必须明确提供，初始点数可以显式为 `0`。密码在终端隐藏输入并二次确认，不接受明文密码命令行参数或管道输入。初始化标记、账号、工作区绑定、凭据和初始额度在同一事务中写入；重复初始化会被拒绝。

登录前读取 CSRF 引导，再提交登录。登录与全部写请求校验准确的 Origin 和 CSRF token。会话采用 HttpOnly、SameSite=Lax Cookie；HTTPS 同时设置 Secure。HTTP 仅在显式 `--insecure-loopback` 且 Origin 为本机来源时允许，不能作为公网部署配置。

密码使用 Argon2id，数据库只保存随机会话令牌的摘要。经管理员开户或重置的密码要求下次修改；改密前只允许本人身份、安全事件、退出和改密接口。桌面启动令牌、owner token、本机 Agent 凭据和默认 local owner 都不能用于平台认证。

浏览器先确认 `/api/runtime` 的可信模式，再进入相应引导。平台在 `/auth/me` 确认账号后才加载工作区；匿名和强制改密期间不创建业务页面，也不读取本地模型配置。平台缓存使用 `platform:<instanceId>:<workspaceId>` 命名空间，实例标识来自数据目录的持久随机标识，账号 ID 不作为内容归属或缓存工作区 ID。

会话失效后原工作区组件及弹窗草稿仍保持挂载，界面隐藏并禁止交互，只允许重新认证原账号或明确放弃。重新认证成功后同步原草稿，不再次水合覆盖它。退出先尝试同步，失败时展示继续同步或明确放弃；缓存清理失败会阻止切换账号。跨标签页通知只传会话标识，不传 token。业务 JSON 请求携带 `X-Platform-Session` 绑定开始时的会话，Cookie 在其他标签页切换后不能把新账号响应写回旧工作区。

已登录页面可见时每 2.5 秒检查一次服务端会话，回到页面时立即检查；隐藏页面停止轮询。该检查不更新服务端的最后活动时间，因此不会延长空闲过期。服务端撤销或身份变化会进入原账号恢复界面，短暂网络失败保留草稿并等待下一次检查。

## 管理员账号维护

管理员从账户菜单进入「平台管理」。用户账号与管理审计分别分页读取；普通用户不显示该入口，管理接口仍在服务端校验管理员身份。管理权限不允许读取其他用户的项目、画布或生成内容。

创建账号必须填写用户名、显示名、角色、初始密码、初始 AI 点数和存储上限；点数和存储上限没有隐含默认值，可明确填写 `0`。存储上限以字节填写，`1 GiB = 1,073,741,824` 字节。用户名创建后不可修改；初始密码与重置密码均要求用户下次登录修改。

账号菜单支持修改显示名与角色、重置密码、启用或禁用，以及逻辑注销。禁用、注销、角色修改和密码重置会撤销旧会话。不能禁用或注销自己，最后一个有效管理员保护由服务端事务执行。注销不会释放用户名和工作区给其他账号。

额度窗口显示当前可用、已结算和预留点数，以及已用和预留存储，并允许修改存储上限。上传已使用持久存储预留，调低上限不删除现有数据，已有预留可以完成，新增和扩展写入会被拒绝。账号菜单中的「调整 AI 点数」接受非零安全整数，正数追加、负数扣减，必须填写 1—500 字原因；服务端拒绝突破已结算与预留下限的扣减。网络失败后保持表单并复用原请求标识，修改实际提交内容后才创建新标识。

「用量记录」按服务端分页读取，可按账号 ID 筛选。页面显示账号、任务、模型、操作、点数、执行状态及是否需要人工核对，不展示提示词或生成内容。点数调整统一记入管理审计，包含操作者、对象账号、时间、点数、原因和调整记录 ID；其他审计也仅展示脱敏差异，不包含密码或用户内容。点数调整和用量管理页面可用不表示生成任务已经开放。

服务端将已提交超过 24 小时、仍未终结的执行标记为待人工核对；只有这些行显示「人工核对」操作。管理员必须选择已核实的终局事实、填写 1—500 字依据并确认已核实，再提交处理：至少一份成功结果结算固定点数，确认未受理或完全失败且未消耗释放预留，完全失败但已消耗则结算并补偿。提交绑定打开窗口时的执行状态；状态变化会返回冲突并保留草稿，不自动覆盖新的执行事实。相同内容的网络重试沿用原请求标识，核对记录追加进入审计。

账号额度窗口中的「核对点数账本」按需重新汇总流水并核对额度账户和未终结意图，展示一致或不一致结论，以及流水条数、发放与调整净额、已结算净额和未结算预留。汇总值按服务端十进制字符串原样显示，避免浏览器数值精度丢失。发现差异时不自动修正账户或覆盖历史流水。

## 模型目录与管理

平台账号可从账户菜单进入「模型目录」，查看自己获授权的稳定模型、能力、各操作固定点数和可用状态。目录只请求平台的 `/api/models/catalog`，不加载本地模型配置、用户自带渠道或插件协议。当前生成开关仍关闭，看到模型和价格不表示已经可以提交生成任务。

管理员在「平台管理」的「平台渠道」中创建渠道、修改名称和启停状态、维护渠道模型或轮换凭据。渠道列表只显示上游主机和凭据存在状态；API Key、Secret Key 和请求头值不回显。轮换时输入完整新凭据并保存为新版本。渠道模型的协议选项来自服务端允许目录，能力编辑复用现有配置组件；已被发布路由引用的渠道模型不能直接修改，应新增渠道模型并发布模型新版本。

「逻辑模型」中维护稳定模型标识，并发布完整的能力、默认选项和路由配置。稳定标识创建后不可更改。编辑先读取当前完整版本，提交携带该版本标识；其他管理员已经发布新版本时，服务端拒绝陈旧提交，窗口保留当前草稿并显示冲突。

模型操作价格必须明确填写正安全整数。每次发布追加一个价格版本，价格窗口展示历史记录；输入 `0`、负数或小数不会自动修正为有效价格。用户账号菜单中的「模型授权」支持跨页选择和明确清空，保存会替换该账号的完整模型授权集合；弹窗等待本次授权读取完成后才允许修改和保存。

渠道、凭据、模型版本、价格与授权操作统一进入管理审计。管理表单不会将凭据写入持久浏览器配置，异步提交结果绑定开始时的会话，失效后的响应不能改写另一个账号的页面。

## 当前接口与后续边界

平台认证前仅开放 `/api/runtime`、`/api/healthz`、`/api/auth/csrf` 的 GET 和 `/api/auth/login` 的 POST。已认证接口包括账号会话、工作区引导、能力标志，以及当前注册的项目、章节、画布/历史/画板、画布目录、提示词定制与风格档案路由。提示词定制仅写入本人工作区记录，全局模板保持只读。准确合同见 HTTP API 中的平台章节。

`GET /api/openapi.yaml` 需要有效会话，文档根据平台进程实际注册的路由生成，包含认证、路径参数、通用响应、文本 SSE 游标与资源 Range 规则；当前还没有逐项枚举业务请求体和数据字段。生成路由存在不代表生成能力开放，应同时读取 `/api/features`。

项目与章节覆盖式修改要求 `expectedRevision`，过期请求返回 `409 revision_conflict`；画布继续使用已有 revision 合同。关联写入需要校验项目、章节、画布及其他引用对象的工作区，管理员没有跨用户内容豁免。

平台已接入渠道与模型管理接口、凭据版本、账号模型授权和只读模型目录。凭据、价格及逻辑模型发布均保留历史版本，管理员修改已被发布路由引用的渠道模型会被拒绝。普通目录仅返回授权模型的能力与固定点数价格，不提供渠道地址、密钥或请求头值。

资源上传和读取已经接入当前账号工作区。客户端统一先申请分片上传，服务端原子检查「已用＋预留＋新增」后才接收数据；平台重启可继续未过期会话。资源就绪与预留结算同事务完成，同物理对象去重计量；超限写入清理临时文件。文件和 Range 均检查归属并禁止浏览器持久缓存。

上传请求持久绑定内容摘要、文件名和媒体元数据。同键更换内容返回 `409 idempotency_conflict`；服务端核验实际字节，篡改内容返回 `409 upload_content_mismatch`。浏览器按固定 8 MiB 分块计算摘要，不把整个大视频一次读入内存。

素材库的列表、详情、目录、批量读取和写入已接入平台。所有资源和目录关联逐项核对工作区，不属于当前工作区的对象统一返回 404。平台删除素材时保留任务、项目、画布及历史引用保护；通过校验后先持久化删除意图，并将素材和资源移出可读、可引用状态，再由现有删除队列清理文件。部分文件失败或最终事务失败时保留原始元数据与已用容量，重启后继续清理；所有对象完成后才原子删除记录并释放容量。旧请求不能复活删除中的素材或复用已经删除的素材 ID。

平台暂不启用旧的孤儿资源自动回收；该路径需接入同样的持久删除意图后再开放，避免提前移除失败或无归属资源的元数据。任务领域已通过仅使用回环模拟上游的文本准入、固定点数结算、凭据冻结、SSE 和中断恢复专项；这不代表所有媒体生成或真实付费验收完成。

平台已注册本人任务列表、详情、日志、文本增量和文本 SSE。客户端文本写入与宣布完成的接口不注册。创建任务和重新生成在正式构造器中仍返回 `403 generation_unavailable`；生产组合根不启动生成 worker，测试包才可启用受限的模拟执行。平台领取器只处理执行意图、任务归属和永久账号绑定一致的任务，没有平台准入记录的历史任务不会被后台自动执行，也不会被展示为可继续取回。

平台已装配文本工作流模板、操作目录和运行接口，复用现有画布工作流调度器与平台任务准入。当前模板只允许文本输入、文本常量和文本生成，模型来自本人授权目录；配方不接受客户端上游地址、请求头、协议或密钥。生产运行与重试仍关闭，读取历史运行不会推进执行。

模拟执行已验证逐步骤预留、额度不足暂停、追加额度后由用户继续，以及已完成步骤不重跑。运行和重试都要求 `clientOperationId`；网络重试保持原标识，重启后按持久回执找回原有子任务，不重复预留或重新提交。同一重试标识不能用于另一个运行。备份恢复或本地导入的运行保留历史和结果，禁止沿用旧运行重投。

以下能力尚未完整交付：资源派生与播放副本计量、媒体生成交付、全部历史版本和模块的隔离导入，以及部署验收。平台不注册自定义模型中转、旧模型配置、助手、本机 Agent、插件/技能、Eagle、运维和环境诊断入口；未注册路径返回 404。真实上游生成保持关闭，健康检查不能替代业务验收。
